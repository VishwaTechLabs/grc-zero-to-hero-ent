# 🔐 Answer Key — Nist Ai Rmf

### Expected mapping
**Requirement/Outcome → Risk → Control → Evidence → Test → Result**

### Model control
The organization defines an accountable owner, performs the required activity at a defined
frequency, retains evidence, monitors exceptions and reviews effectiveness.

### Model evidence
Approved policy + system record + review/approval + exception record + test result.

### Model finding
If evidence is incomplete or the control does not operate as designed, document condition,
criteria, cause, effect/risk, recommendation, owner and due date.
