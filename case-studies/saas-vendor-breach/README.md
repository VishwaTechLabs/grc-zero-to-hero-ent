# 🎬 Case Study — Saas Vendor Breach

## Scenario
A critical SaaS vendor reports unauthorized access; assess contract, incident, privacy, evidence and remediation.

## Student challenge
1. Define scope.
2. Identify assets/processes.
3. Identify risks.
4. Select controls.
5. Define evidence.
6. Test.
7. Recommend treatment.
8. Prepare executive summary.

## Deliverables
Risk register + control mapping + evidence plan + remediation + executive decision.
