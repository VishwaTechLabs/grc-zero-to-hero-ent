## 🌍 What is this?

A **complete, visual, practical GRC learning ecosystem**. Every day is a mini-project,
not just a Markdown lecture.

## 🤖 AI GRC + 🏭 OT/ICS

The program includes dedicated modules for:

**AI GRC:** AI inventory, AI risk, GenAI, shadow AI, privacy, model risk, human oversight,
AI security, AI supply chain, NIST AI RMF, ISO/IEC 42001 and AI incident governance.

**OT/ICS GRC:** SCADA, PLC, DCS, HMI, RTU, Purdue architecture, asset criticality,
safety, availability, segmentation, remote access, vendor risk, IEC 62443 and NIST 800-82.

## 🌐 Freshness / real-world data

The repository contains `data/` with **source links and freshness metadata**. It does not
pretend that a static Git repository is live regulatory advice. Use authoritative current
